# Editing reference

`edit.py` adapts the natural-develop engine from the sibling skill [camera-portrait-edit](https://github.com/GKjohns/camera-portrait-edit) (which isn't required). It generalises the engine to any aspect ratio, adds auto params and auto straightening, and runs as a batch over the picks.

## Source choice
RAW when a sibling exists (rawpy: camera white balance, no auto-brighten, full resolution), otherwise the JPEG/HEIC/TIFF. Photos that are already exported edits (`role=edited_output`, no RAW) get only geometry and sharpening. EXIF is copied from the JPEG (or the RAW's JPEG sibling) with orientation reset, and output is tagged sRGB.

## Params (`edits/<id>.json`)
| param | meaning | auto |
|---|---|---|
| `rotate` | degrees CCW | from near-horizontal/vertical line segments (Hough), applied only when the lines agree and the tilt is 0.15-4 deg |
| `aspect` | `native`, `4:5`, `3:2`, `2:3`, `1:1`, `16:9`, `5:7`, `8:10`; follows the frame's orientation | curator's crop, else config `aspect` |
| `crop_scale` | 1 = largest crop that hides rotation corners; < 1 tightens | 1 |
| `crop_cx`, `crop_cy` | crop centre as a fraction of the frame; slides only as far as the frame allows | 0.5, 0.5 |
| `temp`, `tint` | WB in linear light (+warm, +magenta); keep within about ±0.05 | from near-neutral midtones at 40% strength; skipped when the "neutrals" are clearly coloured light (sunsets, tungsten mood) |
| `ev` | exposure in stops | only clearly dark or washed-out frames, moved halfway; low-key frames with real highlights are capped at +0.3 |
| `hl_knee` | highlight roll-off start (linear luma) | 0.82 |
| `contrast`, `shadows`, `highlights`, `fade`, `white` | hue-preserving luma curve | gentle, from the tonal spread |
| `sat`, `vib`, `skin_protect` | saturation, vibrance (spares saturated colours), how much skin tones are spared | 1.0, 0.12, 0.7 |
| `chroma_nr` | chroma noise blur (luma untouched) | 1.0 |
| `sharp_amt`, `sharp_rad` | output unsharp mask on the full-res file | 50, 1.2 |
| `_auto` | `true` = regenerated by `--reauto`; set `false` to keep your edits | |

Renders are skipped when params, source and output name are unchanged. `--draft` renders only the web and before copies from a half-size develop, which is fast for iterating. `--force` re-renders.

## Critique loop (per pick, 1-3 passes)
Look at `edited/web/<id>.jpg` downsized, next to `edited/before/<id>.jpg`:
- **Straight**: horizon level, verticals vertical. Adjust `rotate` in 0.1-0.3 deg steps.
- **Crop**: subject placement, nothing cut at joints, no distractions on the edges, aspect right for the goal.
- **White balance**: whites and greys neutral unless the light is the point. Skin not orange or grey.
- **Exposure**: no blown skies or skin, shadows open but not grey; p99 luma under ~0.97.
- **Restraint**: no halos, crunchy texture, plastic skin or candy colour. If it looks edited, back off.
Then set `"_auto": false` and rerun with `--ids <code or id>`. A subagent can run the loop and return notes + paths so images stay out of the main context.

## Outputs
`edited/NN-title.jpg` (picks, full resolution, q92), `edited/alternates/*.jpg` (with `--alternates`), `edited/web/<id>.jpg` (2048px), `edited/before/<id>.jpg` (same geometry, ungraded, for the slider), `edited/manifest.json`.
